3区間のオイラー・ベルヌーイ梁＋集中質量。支点（サーボ）から加振した定常強制振動を解き、上から見た揺れを描きます。

このツールが解いている式

座標 x は支点（サーボ）を原点に頭側を正とし、w(x,t) は水平方向の横変位です。区間3（翼端部）は −(X₂+X₃)〜−X₂、区間2（翼根部）は −X₂〜0、区間1（胴体）は 0〜X₁ です。定常解 w = Im[ W(x) e^{iΩt} ] を仮定し、各区間の一般解の係数 12 個を連立方程式で求めています。減衰 η を入れると曲げ剛性を EI(1+iη) とする複素剛性モデルになります（η = 0 で前回導出した式そのものです）。

支配方程式   m_i ∂²w/∂t² + E_iI_i ∂⁴w/∂x⁴ = 0      m_i = M_i / X_i
一般解       W_i = A cos βξ + B sin βξ + C e^(−βξ) + D e^(−β(L−ξ))
             β_i⁴ = m_i Ω² / (E_iI_i)

翼後端 x=−b  E₃I₃W'' = 0 ,   E₃I₃W''' = M_D Ω² W
継ぎ目 x=−a  W, W', EIW'' が連続 ,   E₂I₂W'''(−a⁺) − E₃I₃W'''(−a⁻) = M_C Ω² W
支点   x=0   W(0⁻) = W(0⁺) = 0
  トルク指令   W'(0⁻) = W'(0⁺) ,   −J_A Ω² W'(0) = T₀ + E₁I₁W''(0⁺) − E₂I₂W''(0⁻)
  角度指令     W'(0⁻) = W'(0⁺) = Θ₀
  相対角指令   W'(0⁻) − W'(0⁺) = Ψ₀ ,   −J_A Ω² W'(0⁻) = E₁I₁W''(0⁺) − E₂I₂W''(0⁻)
機首   x=X₁  E₁I₁W'' = 0 ,   E₁I₁W''' = −M_B Ω² W

支点反力     R = E₁I₁W'''(0⁺) − E₂I₂W'''(0⁻)
固有振動数   T₀ = Θ₀ = Ψ₀ = 0, η = 0 として 係数行列の行列式 = 0 となる f

減衰なし（η = 0）では共振点で振幅が理論上無限大になります。振幅の見積もりには η = 0.02〜0.05 程度を入れると現実的です。MA は支点上にあり横に動かないため、結果には回転慣性 JA だけが効きます。
